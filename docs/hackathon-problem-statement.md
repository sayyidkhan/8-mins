# Hackathon problem statement

> Use AI to build something a youth would choose to open, and that leaves them understanding more about drug abuse, more willing to talk about it, or more likely to do something. It has to be interactive, and it has to be built in Google AI Studio. What shape it takes is entirely yours: a game, a chatbot, a quiz, an interactive story, a tool. Nobody is going to tell you what to make.

That is the whole brief: the product format is entirely open.

## The hook

> You have someone's attention for eight seconds. Build something with AI that earns the next eight minutes.
